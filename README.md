# 三亚大东海 · 节点设计方案 —— HTML 3D 汇报版

把 PPT《三亚大东海-节点设计方案TL》（7 页）做成了**可缩放/旋转的真实 3D 场景 + 逐页滚动叙事**：
滚一下鼠标（或点按钮/方向键）进入下一阶段，镜头平滑飞行，建筑升起/下沉、变色、透明，卡片与右下角指标面板随之动画变化。

## 1. 打开方式
- **双击 `index.html`**（封面，可点击任一阶段）或直接双击 **`story.html`**（演示本体）。不需要服务器，`file://` 即可。
- 推荐 Chrome / Edge（新版）。全屏：右上角 ⛶ 或 F11。
- 全部依赖都在文件夹里（MapLibre GL、three.js、白模/地形数据、图片）。拷贝时**整个 `web` 文件夹一起拷**。
- 只有"远景底图"需要联网；断网也能完整演示（白模 + PPT 海滩/海水底图）。

## 2. 操作
| 动作 | 方式 |
|---|---|
| 下一页 / 上一页 | 鼠标滚轮或触控板滑动（**一次手势只翻一页**）；`→ ↓ 空格 PgDn` / `← ↑ PgUp`；底部 ▲▼；右侧圆点 |
| 直达某页 | 数字键 `1`–`7`，`Home`/`End`；右侧圆点（悬停显示标题）；网址后加 `#5` |
| 平移 | 左键拖拽 |
| 旋转 / 俯仰 | 右键拖拽（或 Ctrl + 左键拖拽） |
| 缩放 | **Ctrl + 滚轮**、触控板双指捏合、右下角 ＋/－ |
| 滚轮改为缩放地图 | 按 `M`，或点底部「滚轮：切换阶段」按钮切换 |
| 回到本页镜头 | `R` 或底部「复位视角」 |

> 为什么这样设计：汇报时最常用的是"滚轮翻页"，所以滚轮默认翻页、且做了防抖（一次滑动 = 一页，惯性滚动不会连翻）；
> 需要自由观察时，拖拽/右键旋转随时可用，缩放用 Ctrl+滚轮或捏合；想长时间自由浏览，按 `M` 把滚轮切回地图缩放。

右上角 ☰ 设置面板：
- **底图**：离线白模｜白模 + OSM 远景（默认）｜白模 + 高德标准｜高德卫星｜Esri 卫星。
  高德使用 GCJ-02 坐标，切换时白模、设计图层、镜头会**自动做 WGS84→GCJ-02 偏移**，与高德底图对齐。
  国内访问 OpenFreeMap 失败或 9 秒内没有加载出来，会**自动切换到高德**并提示。
- **锁定 PPT 视角**：每一页都用 PPT 原图的机位（已从渲染图反算出相机：方位 −34.7°，俯仰 50.8°，视场 12.9° 近似轴测）。
- **轴测 / 透视**：视场角 12.9°（接近 PPT 轴测效果）↔ 40°（更有纵深感）。
- **对比原 PPT**：叠加 PPT 渲染图，可调透明度，用于核对位置。
- **图层开关**：每个设计元素可单独显示/隐藏。

网址参数（可组合）：`story.html?basemap=amap-std#4`（以高德底图打开第 4 页）、`?offline`（不连任何网络）、`?ppt`（锁定 PPT 视角）、`?nopanel`（隐藏指标面板）、`?wheel=zoom`（滚轮默认缩放）。
basemap 可选：`model`、`model-ofm`、`amap-std`、`amap-sat`、`esri-sat`。

## 4. 修改每一页（steps.js）
每一页是一个对象，主要字段：
```js
{
  title: '通过改造加建打造都市潮流酒店', en: 'TRANSFORMING AND EXPANDING ...',
  camera: { at: [-80, 20], dz: 0.75, bearing: -14, pitch: 56 },   // 镜头：设计原点为 0,0 的米坐标；dz=相对 PPT 机位放大级数；或 { ppt: true }
  base:   { opacity: 1, color: '#f4f3f1' },                       // 周边白模透明度/颜色
  layers: { ex_slab_e: { o: 0, g: 0 }, s3_hotel: { o: 1, g: 1 } }, // 3D 图层：o=透明度 g=高度(0 沉入地下→1 完整) c=颜色 ca=变色程度
  flat:   { s5: 1, cut: 0, bounds: 0 },                           // 平面图层（景观铺装/草坪/水、地面开挖、红线）
  cards:  [ { title, en, gfa, desc, descEn, photo, accent, anchor: [x, y, 高度], box: [左%, 上%] } ],  // anchor=PPT 原图 4000×2250 像素坐标
  panel:  { above: [['hotel', 16000], ['com', 30000]], below: [...] }  // 指标面板（数字自动滚动动画）
}
```
- 未在某页 `layers` 里列出的图层：`ex_*`（现状）默认显示，其它默认隐藏；新增的 `s<N>_*` 模型从第 N 页起显示。
- 动画规则：先淡出/下沉旧元素，再升起/淡入新元素（延迟 45%），镜头 2.2 秒缓动飞行；时长在 `config.js` 调整。

## 5. 放入 Rhino 模型（替换占位体块）
目前的酒店、公寓塔楼、Summer Sphere 等都是**占位体块**，按 PPT 图像位置摆放。拿到 Rhino 模型后：

1. 在 Rhino 中按图层命名（顶层图层名 = 网页图层 id，例如 `S3_HOTEL`、`S6_TOWER`、`S7_SPHERE`、`EX_XIARI`；完整对照表见 `../work/RHINO_NOTES.md`）。
   单位米，X 东 Y 北 Z 上；Rhino 原点 = 东经 109.5205°、北纬 18.2240°（或用参考点/测绘坐标，转换器可处理）。
2. 运行转换器（盒子里已装好 rhino3dm）：
   ```bash
   cd /workspace/dadonghai
   .venv/bin/python work/rhino2glb.py 你的模型.3dm
   # 参考点配准：--ref 512.3,-88.0,109.52067,18.22397（Rhino 点 x,y = 经度,纬度；高德拾取的坐标加 --gcj）
   # 测绘坐标：  --crs EPSG:4547
   ```
   生成 `web/models/<图层>.glb` 和 `web/models/models.js`（GLB 以 base64 内嵌，所以双击 file:// 也能加载）。
3. 重新打开 `story.html`，同名图层的占位体块会被真实模型替换，并沿用该图层的全部动画。
4. 临时预览：直接把 `.glb` 文件**拖进页面**（文件名 = 图层 id，如 `s3_hotel.glb`；或一个包含多个图层节点的 glb）。

也可以用 Rhino 8 自带的 glTF 导出，详见 `../work/RHINO_NOTES.md`。

## 6. 哪些是"忠实还原"，哪些是"占位"
- 忠实：PPT 的机位（反算）、全部文字和数字（逐字取自幻灯片 XML）、卡片版式/颜色、指标面板构成；
  场地位置（OSM 真实建筑轮廓）、海滩海水（PPT 渲染图纠正贴图）、第 1 页红线范围、第 4 页地下空间范围、第 5 页景观铺装/草坪/水面/树位（均由 PPT 渲染图反投影得到）。
- 占位：ACE 酒店、公寓塔楼与板楼、商业小体量、连桥、Summer Sphere、玻璃顶、观景塔等**体量与高度**；树为程序化简模；周边白模高度来自 OSM（部分为估算）。

## 7. 已知限制
- 周边建筑高度来自 OpenStreetMap，部分建筑无高度数据时按层数/类型估算，与 PPT 渲染模型不完全一致。
- 高德底图在 `file://` 下可直接用；如所在网络屏蔽 OpenFreeMap，首次打开会等待约 4 秒后自动切换高德。
- 低配电脑（集成显卡）上第 5–7 页（大量树和体块）帧率可能下降；可在设置中关闭树图层。
